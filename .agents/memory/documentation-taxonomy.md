---
name: Documentation taxonomy versus product support
description: How to use a third-party documentation reference without implying unsupported product capabilities
---

Treat the NordRouter documentation structure as a navigation reference, not as proof that Stratus Hub supports every listed client or API feature. Publish a guide only after the corresponding Stratus Hub behavior and client settings can be verified; otherwise mark it as planned.

**Why:** The reference site has dozens of integrations, while Stratus Hub currently exposes a visual preview and illustrative API examples rather than a confirmed live API. Copying third-party instructions would mislead users and could prompt them to expose credentials to an unverified endpoint.

**How to apply:** When expanding documentation, verify supported endpoints, model identifiers, credentials, limits, and client-specific settings against the actual product before replacing a planned topic with an instruction.
